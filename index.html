Super Smash Bros.

This series is a self-made titan that has been a major part of many kids childhood. This is a w.i.p. So all it's good for now is being a link to the main website.

This is the game that started it all. Compared to it's future installments, it is pretty bare as far as Smash Bros standards go today. However, this game has it's own charm with it's ridiculous combos and it being the first time you could see not only a large crossover of nintendo characters, but you could also make any of them fight like action figures from a toy box. Which is exactly what the game shows in its intro.

This game is the second installment in the series. When it released, it was not a fully polished game. It worked like it was supposed to, but it had it's fair share of glitches and exploits. This fact, however, led to Melee being one of the most popular games in the series.
